# Features

DocStack includes everything you need for a modern documentation site.

## Core Features

### Markdown Support

Write your documentation in standard Markdown with GitHub-flavored extensions:

- Fenced code blocks with syntax highlighting
- Tables
- Task lists
- Automatic heading anchors

### Automatic Navigation

Your content structure becomes your navigation:

- Top-level folders = Header tabs
- Nested folders = Sidebar sections
- Markdown files = Pages

### Dark Mode

DocStack automatically detects your system preference and switches between light and dark themes.

### Responsive Design

Works great on desktop, tablet, and mobile devices.

## Admin Features

### Built-in Editor

Enable `FEATURE_EDITING=true` in your `.env` file to get a Monaco-powered editor for content management.

### Password Protection

Add a `.protected` file to any section to require password authentication.

## Customization

### Branding

Configure via `.env`:
- Site name and emoji
- Custom logo
- Primary colors
- Footer text

### Custom Styles

Add `custom.css` for additional styling without modifying core files.
