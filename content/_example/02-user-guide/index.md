# User Guide

This section demonstrates how multiple tabs work in DocStack.

## Overview

Each top-level directory in your content folder becomes a tab in the header navigation:

- `01-getting-started/` becomes the "Getting Started" tab
- `02-user-guide/` becomes the "User Guide" tab
- And so on...

## Example Use Cases

Common documentation sections you might create:

| Section | Purpose |
|---------|---------|
| Getting Started | Installation, setup, quick start |
| User Guide | Feature documentation, how-tos |
| API Reference | Endpoints, methods, parameters |
| Examples | Code samples, tutorials |
| FAQ | Common questions and answers |
